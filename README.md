# ربات دستیار کانال نکات و ترفندهای پیانو

هر روز خودکار ۱۰ تا نکته/ترفند/نکته‌ی تئوری پیانو (متفاوت با روزهای قبل) می‌سازه و برای تأیید
برات توی تلگرام می‌فرسته. با ریپلای، همه یا بعضی‌هاش رو تأیید می‌کنی؛ هرکدوم که تأیید بشه به‌عنوان
یک پست جداگانه توی کانالت منتشر می‌شه.

بر خلاف پروژه‌ی اخبار هوش مصنوعی، این پروژه منبع RSS نداره — محتوا مستقیم از دانش خودِ مدل زبانی
(Groq) ساخته می‌شه و برای جلوگیری از تکرار، عنوان‌های روزهای قبل رو یادش می‌مونه.

همه‌چیز روی سرورهای رایگان گیت‌هاب اجرا می‌شه؛ لپ‌تاپت هیچ نقشی نداره.

## مراحل راه‌اندازی (یک‌بار انجام می‌شه)

### ۱. ساخت ریپو
یه ریپوی **پابلیک** جدید بساز (مثلاً `piano-tips-bot`) و همه‌ی فایل‌های این پوشه رو توش قرار بده
(دقیقاً مثل پروژه‌ی قبلی: یا با Upload files برای پوشه‌های config/data/scripts/tests و بعد
فایل‌های داخل `.github/workflows` رو تک‌تک با «Create new file» و تایپ کردن مسیر کامل بساز).

### ۲. کلید Groq
اگه از پروژه‌ی قبلی کلید Groq داری، همون رو دوباره استفاده کن. وگرنه از
[console.groq.com](https://console.groq.com) یکی رایگان بساز.

### ۳. بات و کانال جدید
- توی تلگرام با @BotFather یه بات جدید بساز (`/newbot`) و توکنش رو نگه دار.
- بات رو ادمین کانال جدیدت کن (با دسترسی Post Messages).
- آیدی عددی چت خودت رو با @userinfobot بگیر (یا از قبلی استفاده کن، همون آیدیه).
- اگه کانالت یوزرنیم عمومی داره (مثل `@my_piano_channel`)، همون یوزرنیم TELEGRAM_CHANNEL_ID می‌شه.

### ۴. وارد کردن Secrets
توی ریپوی جدید برو: `Settings → Secrets and variables → Actions → New repository secret`
و این ۴ تا رو بساز:

| نام Secret | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن بات جدید |
| `TELEGRAM_ADMIN_CHAT_ID` | آیدی عددی چت خودت |
| `TELEGRAM_CHANNEL_ID` | آیدی/یوزرنیم کانال جدید |
| `GROQ_API_KEY` | کلید Groq |

### ۵. فعال‌سازی
برو تب Actions، ورک‌فلوها رو فعال کن، و برای تست فوری روی «Daily Piano Tips» → «Run workflow» بزن.

## نحوه‌ی کار روزانه
1. هر روز ~۹:۳۰ صبح، بات ۱۰ تا نکته‌ی شماره‌دار برات می‌فرسته.
2. برای تأیید همه: فقط بنویس `همه`
3. برای تأیید بعضی‌هاشون: شماره‌ها رو با ویرگول بنویس، مثلاً `1,3,5,7`
4. هرکدوم که تأیید بشه، به‌صورت یک پست جداگانه توی کانال منتشر می‌شه (نه یک پست بزرگ).

## تنظیمات قابل تغییر
- **تعداد نکات روزانه**: متغیر `NUM_TIPS` توی `scripts/generate_tips.py`
- **لحن/دسته‌بندی محتوا**: متغیر `SYSTEM_PROMPT` توی همون فایل
- **زمان اجرای روزانه**: خط `cron` توی `.github/workflows/daily_tips.yml`

## تست
```
pip install -r requirements.txt
python3 tests/smoke_test.py
```
باید در آخر `ALL TESTS PASSED` رو ببینی.
